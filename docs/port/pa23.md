## Completed coherent behavior group

`dev/src/sema/final_overriders.rs` owns semantic subobject containment,
unique-final-overrider validation and grouped-class abstractness. It translates
C++'s compressed segment/primary-chain dominance rules using explicit dynamic
subobject identities. ABI sharing is a later projection; semantic containment
needs neither byte offsets nor a primary virtual base's physical placement.

A checked compact `SubobjectId` identifies each nonvirtual occurrence. A
class-keyed shared-virtual index merges all paths to one virtual subobject;
nonvirtual occurrences of that same class stay distinct. Flat parent edges
capture containment, including virtual bases of virtual bases. Final witnesses
retain both subobject and `EntityId` identity: two occurrences of the same
function do not collapse. A candidate dominates another only when its actual
subobject contains the other, rather than merely deriving from its class.

Typed `VirtualSignature` keys preserve name, parameter/cv/ref identity and the
conversion target for conversion operators. Destructors share the language's
one destructor signature. Completion includes declared functions, synthesized
virtual destructors and implicit assignment operators. Assignment override
discovery now examines secondary roots as well as the first base branch,
performing the existing covariance/access/exception checks for every match.

Explicit query worklists memoize complete `(SubobjectId, VirtualSignature)`
keys. Only ancestors of a requested virtual declaration are queried; unrelated
siblings' signatures are not multiplied together. Immutable candidate ranges
share one flat store, merge buffers are reused, and containment queries reuse
scratch and memoize complete subobject-pair keys. Declaration indexes, dependency worklists and parent edges use flat stores,
with no vector allocation per node. These query stores die at class completion;
the semantic graph retains the chosen final-overrider/pure witnesses for
abstractness. A class extending one dynamic base applies its own declarations to
the base's completed witnesses (`group_splice`'s chain case), preserving
occurrence identities without rebuilding the transitive ancestor graph. Only grouped classes need this representation; ordinary primary
chains keep their compact delta recipe, now seeded by the first dynamic base
rather than a preceding non-dynamic base.

The semantic unit owns `Virtuals` behind one `Box`, reducing analyzer move-frame
size while retaining its original unit lifetime. There is no per-node boxing,
shared mutability, new dependency, text transport, repeated parsing, body
instantiation, speculative layout, global retry or environment access.
`declarations.rs` passes the original class-key location into completion;
`initializer_lists.rs` preserves its synthetic builtin location. Lowering,
optimization, native generation and register allocation were not changed.

The complete group covers valid and invalid hierarchies, not just the four
newly passing rejections. Six unit invariants exercise virtual diamonds,
repeated nonvirtual occurrences, implicit destructors, overload separation,
conversion targets, secondary-root implicit assignment, and containment-based
ambiguity. They also verify no syntax duplication, storage layout or emission
demand on declaration-only inputs. Generated supported semantic/LowIR probes
exercise wide unrelated signatures batches of valid virtual diamonds and deep derived chains with periodic
overrides.
