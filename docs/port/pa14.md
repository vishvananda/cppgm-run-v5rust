one signature. A potentially evaluated selected use queues that specialization's
body independently of emission. Signature-only friends and unevaluated uses do
not queue it. The queue observes a definition declared later in the unit and can
append further demands without rescanning unrelated declarations. Repeated and
recursive calls reuse the entity and body state. A template with no definition
retains a declaration; no successful empty-body substitute is synthesized.

A definition records its own template head, even after earlier heads were merged
or a qualified declarator introduced a lookup bridge. Instantiation binds only
that head's aliases into a frame parented at the definition's context. The stored
namespace ordinal excludes later overloads and directives. The specialization
entity supplies friendship/access identity, so a friend grant to a sibling cannot
authorize its private accesses.

The driver exclusively lends the syntax slabs for copying between immutable
analysis sessions. Every read of an instantiated occurrence uses a normal dense
ID and its own facts, with no pattern lookup or environment map per node read.
The graph owns all persistent facts, while session scratch is reclaimed per body.
Pending function/storage/constructor/destruction boundaries are visited once after
the body worklist finishes, avoiding a full demand traversal per specialization.
Lowering retains its existing per-function lifetimes, emission order, optimizer
and register allocator. No source reparsing, second semantic tree, unsafe code,
FFI, subprocess implementation, new dependency or environment access was added.
