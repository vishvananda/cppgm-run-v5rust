   unused class and alias patterns; and

## Architecture and production invariants

The parser retains one syntax tree. Head and argument formation consume that
syntax and publish immutable TypeIds and compact EntityIds. Parameter position
and head shape remain separate from declaration defaults: equivalent positional
parameters can carry different default syntax and definition scopes. An instance
frame retains the declared parameter entity while its alias binding carries the
bound template-name TypeId. No template-name identity uses text or a mangled name.

A positional template-name owns one undefined stand-in template per canonical
TypeId. Dependent member names retain qualifier/name identity in their existing
store. These unit-owned keys are immutable and need no invalidation; class shells,
class definition/layout, member bodies and emission retain separate demand.
Class completion never defines a stand-in. The stand-in cache is boxed to keep
unit analysis frames small. Deduction consumes canonical actual-template identity
and flattened argument partitions; it does not parse or re-render a template-id.

A written expansion remains recorded after zero/nonzero expansion. An unexpanded
`TT<>` first supplies the declared parameter's defaults; specialization then uses
the bound template's arguments and defaults. Already partitioned pack arguments
flatten only at this written-list boundary, using the shared owning pack API.
Dependent template-name substitution resolves the name before substituting its
argument list, preserving C++ demand and failure order. Failed reconstructions
publish no successful alias specialization or class default cache entry.

Template-name ADL contributes the owning namespace or enclosing class; it never
walks the template definition's bases. Pack arguments contribute their elements.
ABI lowering reads the recorded name/arguments and keeps per-function backend
lifetimes. No optimizer, register allocator, emission-order policy or native
encoder change was made. No unsafe, FFI, compiler fallback, fixture recognition,
new dependency, text phase transport, blanket lint suppression or unrelated
whole-program work was introduced. Source limits pass the companion audit.

Two unit tests verify canonical template argument identity and class-shell reuse,
parameter-owned defaults despite shared positional shape, no argument-class/body
or emission demand, unchanged syntax/binding stores on cache hits. Executed fixed
PA17 tests and 29 supplemental exact probes cover head kind/arity/pack rejection,
recursive heads, defaults, aliases, expansion, deduction/reconstruction, ABI names
and ADL. Temporary sources and measurements live under A only.
