## Architecture review

Arguments are parsed once and converted with the existing argument/default/pack
APIs. Alias identity is its declaration EntityId plus canonical argument TypeIds;
a member alias's declaration identity belongs to its concrete owner scope. The
retained semantic type pattern, expression operands and immutable substitution
frames retain declaration-scope lookup and pack selections. Own positional
arguments return the existing pattern without walking it again. Successful
canonical alias results are memoized; failed attempts publish no successful
entry and remain retryable when a class gains declarations.

A dependent argument that an alias drops remains in an undefined stand-in's
specialization key (CWG 1558). Substitution re-forms that alias and can still fail
on a discarded dependency. Deduction, declaration agreement and ABI each consume
the recorded aliased type at their owning boundary. Declaration equivalence is
separate from substitution identity, including a class specialization containing
an alias stand-in. Representatives are registered before publication and require
no global cache invalidation. Class shape/layout, member bodies and emission keep
their existing independent demand states.

The alias caches and declaration-equivalence facts are boxed unit-owned stores;
this keeps the driver analysis frame within strict Clippy's stack limit. The
named-parameter DAG walk reuses scratch and honors C++'s semantic opacity/depth
rule; it does not tune physical stack cutoffs. The genuine byte-budget guard and
logical instantiation limits remain unchanged. No syntax replay, textual phase
transport, semantic lookup in lowering, unrelated-program scan, unsafe, FFI,
compiler fallback, new dependency or blanket lint suppression was introduced.
Optimizer, allocator, native emission policy and per-function backend lifetimes
are preserved. The only lowering change is the translated transparent alias ABI
edge, validated with exact demanded-function LowIR/ABI probes.

Two unit tests check hidden binding/cache reuse, default/cv identity, absence of
class definition demand, discarded dependency retention, declaration equivalence,
failed versus successful substitution and unchanged syntax storage on repeated
queries. Existing executed PA17 fixtures cover the language behavior. Temporary
supplemental inputs and resource workloads are retained only under A.
