## Next dependency boundary

Retain an address parameter's target in value-operand patterns through dependent
signature substitution, including the target's own substitution and complete
cache identity. C++ `template_placeholders.cpp::substitute_value` evaluates the
copied operand with the placeholder's `value_type`; Rust's `Pattern` currently
retains the expression/environment but its value query calls `template_value`
without that target. Consequently `helper<&T::const_cast_from>` cannot deduce a
static member function template from its substituted function pointer signature.
The fixed case `tests/general/300-static-member-template-function-pointer-nttp.t`
exposes this boundary. Port target ownership and candidate failure timing
coherently; do not choose an arbitrary overload or render/reparse the signature.

Unknown explicit argument heads also need C++'s linked integral-object duality:
retain the designation until a reference parameter binds it or an integral
parameter reads its constant value. That is separate from the concrete targets
ported here. Other remaining PA18 groups include non-deduced partial ordering,
array/braced deduction, dependent calls/aliases/decltype replay, elaborated-type
SFINAE, conversion-template targets and constructor participation. PA18 remains
active; Ralph owns checkpoint audit, advancement and the last-audited commit.

## Architecture review and audit questions

The new paths consume the existing parsed AST and typed bindings; none create a
text transport or a second semantic tree. Sparse argument facts live only in the
unit's address store, keyed by compact binding/entity IDs. Demand indexing uses
one `(context, function)` probe and explicit per-context order, never whole-program
scans or hash iteration for output. ABI entity names use the existing variable or
function encoding owner, rather than an integer encoding of an entity or a
rendered-name lookup. Class aliases form shells without demanding definitions.
Per-function LowIR/backend lifetimes and existing optimizations are preserved.

Audit the target-dependent operand key and unknown integral-object conversion
before claiming full address-argument completion. Check qualification conversions,
internal-linkage specialization locality, reverse first-use demand order and
rejected/unevaluated candidates independently of fixture counts. No oracle or
harness defect has been established in this group. Resource probes use the
protected adapter and judge its `match`/`stack_qualification` receipt; no native
stack depth or exhaustion diagnostic position is calibrated.
