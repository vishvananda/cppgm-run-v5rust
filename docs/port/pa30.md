## Mechanism and ownership

C++ `sema/constant_evaluator.cpp::constant_value` chooses its evaluator from the
operand's own facts. Rust `sema/constants.rs` now requires recorded glvalue facts
before reading interpreter storage, even when an outer constexpr frame is live
while class completion evaluates an untyped nested template constant. Existing
interpreter frames, typed operands and definition-time evaluation stay separate.

C++ `sema/analyzer_copy.cpp::declare_implicit_copy_members` treats a closure's
deleted copy assignment as declared, suppressing both implicit move members.
Rust `sema/copy_properties.rs` applies that same predicate to construction and
assignment. Rvalue closure operands select the copy constructor and its existing
subobject plans. All three affected hosted `std::function` objects now match.

C++ `sema/analyzer_initialization.cpp::list_argument` materializes reference
list temporaries whose destructors `lower/cleanup_lowering.cpp` demands later.
Rust `sema/initialization.rs` records the containing body's output destruction
edge through `sema/destruction.rs`; initializer-list backing arrays reuse it.
Containment preparation records parent-owned edges instead of eagerly demanding
child definitions. The existing `sema/layout.rs` reachability worklist demands
only reached destructor bodies before lowering. `object_lowering.cpp`'s optional
`needs_destruction` query preserves unpublished nested-class and implicit-union
destructor boundaries. Lifetimes of class prvalues and reference-conversion
temporaries use the same output edges; reached constructor plans independently
demand subobject destructors for failure cleanup. This preserves the oracle's
private-destructor acceptance here and leaves invalid destructor bodies of unused
inline temporaries and their members undemanded. Lowering still requires facts.

New PA14/PA15/PA20 controls cover these boundaries in their executed lanes; two
unit regressions check occurrence/frame ownership and closure copy facts,
including a captured class with a deleted move constructor. The
[source map](source-map.tsv) and [architecture review](../../artifacts/pa30-initializer-facts/architecture-review.txt)
trace the producers and consumers. No new persistent field, cache, syntax replay,
