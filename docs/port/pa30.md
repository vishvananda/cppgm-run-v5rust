## Mechanism and owners

- C++ `lower/aggregate_lowering.cpp::copy_object` maps to Rust
  `lower/object_storage.rs`. Class address sources transfer `min(size,nvsize)`
  when `nvsize != 0`; typed LowIR object temporaries transfer the full value.
  Constructor bodies, argument materialization, conversion/call results and
  related consumers share this rule. Arrays retain padded stride; explicit byte
  spans retain their owner. The builder queries its private typed temporary store.
- C++ `cleanup_lowering.cpp::{emit_call,split_region,open_region}` and
  `local_static_lowering.cpp` map to Rust `lifetime_regions.rs`, `lifetime.rs`
  and `local_storage.rs`. Throwing calls use saved operand/segment boundaries;
  nonthrowing calls use the ordinary storage event. Both storage-split producers
  consume the eager start; a fresh full expression starts it again. A consumed
  split reopens after operands, preserving allocated reference-conversion
  completion and static guard abort/retry/completion order.
- C++ `native/select/emit_calls.cpp` maps to Rust `native/call_selection.rs`.
  Unused-result builtin memcpy inlining requires the **Course** model. **Host**
  keeps the libc call and relocation. Existing resolved builtin facts preserve
  symbolic aliases; optimizer, register allocation and staging policy are retained.
