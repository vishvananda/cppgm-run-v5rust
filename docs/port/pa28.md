## Completed coherent group: canonical ABI tags

The existing parsed `Attribute` lists retain first-attribute grouping and
continued operands. Analysis validates plain/u8 concatenated identifier tags,
interns them as compact `NameId`s, and publishes sorted unique slices on
private typed `EntityId` or inline-namespace `ScopeId` owners. Existing binding
ordinals identify redeclarations; a later declaration may repeat a subset,
but cannot add a tag. Instance data members/typedefs reject tags, static data
members retain them, and a completed class ignores later elaborated tags
only after operand validation, as the frozen owner does. Ordinary rejection
locations and ordering remain exact, including a lone class's name location.

Lowering consumes these facts through typed APIs. Specializations use their
template's explicit name tags; member classes use their pattern's. The common
ABI identity reaches ordinary methods, constructors/destructors, aliases,
RTTI/type names and virtual support symbols. Function results and variable
types contribute only tags absent from the underived name/signature. This
includes local statics and their guards, hidden inline namespace tags, and
C-linkage/global bare-name exceptions. Typed in-progress callable encodings
break local-result naming recursion without reparsing or speculative bodies.

`abi/tags.rs` iteratively walks canonical `NodeId` edges, caches sets of at
most eight tags per node/mode, and uses a visited query for larger sets.
Underived edges prevent derived tags from recursively contributing through
local function contexts. Written-scope mode excludes hidden namespace tags
inside local encodings. Query storage belongs to the ABI graph and is included
in its measured reserved bytes; it is reset with that owner.

The complete callable-encoding responsibility moved from `symbols.rs` to
`callable_encoding.rs` to keep the implementation file within its audit cap.
Its signature/entry/parameter order is preserved. No optimizer, instruction
selector, register allocator or backend lifetime policy changed. Syntax is
parsed once; stored semantic facts feed typed ABI nodes and LowIR directly.
No new dependency, unsafe code, compiler subprocess fallback, fixture
recognition or whole-program scan was introduced.
