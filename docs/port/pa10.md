Completed production behavior and invariants:

- Reference parameters and locals use pointer holders. Each access first loads
  the holder with an unqualified typed pointer load, then addresses or reads
  the referent with its own recorded type/cv. Reference results cross as `ptr`;
  returns bind source storage, calls returning references supply places, and
  scalar value consumers explicitly load those places. Scalar, pointer,
  function and existing array referents share this address path.
- Reference arguments consume retained semantic conversions. Direct bindings
  preserve one computed place and its effects. Converted scalar temporaries
  use the recorded object TypeId; ordinary scalar prvalues bind their referent
  type. tmpref/refarg/retref storage stays with the function. Its initialization
  is an unqualified access even when the referent is volatile. An unconverted
  conditional temporary reuses the condition's value slot and retains the
  C++ repeated store. Braced declaration initializers unwrap only at the
  reference-initializer boundary.
- Reference casts preserve scalar/function/array addresses; converted cast
  temporaries bind through the recorded cast target. Comma, assignment,
  prefix update and conditional reference designators keep source effects.
  Unary logical-not compares the raw truth operand once, without first
  applying the semantic boolean conversion shell. Scalar conditional *value*
  reads use a value slot with branch-local loads;

  decay continues to consume the selected array address. This corrects the
  remaining scalar conditional-value mismatch without adding an optimization.
- Discarded direct/indirect calls retain their effects without loading their
  reference results, including volatile results. Discarded volatile lvalue
  reads follow C++'s specified id/subscript/indirection/conditional/comma forms;

  lists and scalar-literal place requests use the actual rejection diagnostics,
  not status 86 as a substitute for a rejection.
