retain TypeIds; no result deduction copies an ordinary body or reparses text.

private syntax/fact storage through the existing cloner. The original template
signature keeps auto; its selected specialization receives its own concrete
signature. Canonical type records remain immutable.

Function identity, overload signatures, specialization argument keys and body
state stay with their existing EntityId/BindingId/TypeId owners. Return types
do not key ordinary overloads. Result publication does not scan declarations,
clear caches or retry unrelated bodies. The canonical entity signature is the
current callable fact; historical declaration syntax remains separately owned.
Function-origin binding publication supports existing views and call metadata.

The existing body state detects recursive result demand and memoizes successful
instantiation once. A known result does not demand the body again. A plain
non-template forward declaration does not become a definition request. Explicit
unevaluated result queries demand only the type-required specialization body;
ordinary decltype of a function declaration retains the oracle's permissive
behavior. Body availability and emission remain separate; unused invalid
members/templates are not instantiated, and their definitions are not emitted.

Function/body and callee-name contexts restore through Result. New tests check
one selected specialization and one body copy despite repeated demands,
unchanged original template type, concrete type/body identity reuse, no new
ordinary expression/statement/body syntax, reference collapse, cv qualification
and void inference. External probes exercise raw diagnostic/output behavior.

No optimizer, code generator, register allocator or backend lifetime policy is
changed. No unsafe code, dependencies, FFI, subprocess implementation, source
recognition, reference answers or protected scaffold/input/checker/oracle/state
changes are introduced. Resource checks retain the real stack byte-budget guard;
they judge the protected adapter's `match` and qualification receipt rather
than native exhaustion depths or diagnostic positions.
