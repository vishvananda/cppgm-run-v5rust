## Completed behavior group and architecture review

Ordinary declared virtual members retain sparse `EntityId` facts in the unit's
original semantic Graph. A private class/name/canonical-signature index and a
unit signature filter limit override search to indexed base edges. Search
visits a base once per query and stops on the nearest matching declaration.
Canonical parameter/cv/ref signatures exclude the return type; conversion
function signatures retain their conversion target. No rendered names are
semantic keys, and no syntax is copied or reparsed.

The declaration checks preserve first-declaration restrictions, repeated
virt-specifier locations, static/constructor/union/friend/nonmember rules,
`override`, method `final`, deletedness and constexpr diagnostics. Covariance
uses typed class identities, cv/ref shape, completeness and unique accessible
base paths without demanding storage layouts. Pure specifiers require the
literal spelling `0`. Primary-chain pure counts are completed once per class,
including clearing an inherited pure destructor through an implicit override.
Abstract object checks cover ordinary variables/members, declared function
boundaries, arrays, class prvalues, explicit casts, allocation and by-value
argument uses; pointers and references retain their separate rules.

Exception validation distinguishes declaration-time nonthrowing checks,
complete-class finite-set comparison, and pending noexcept operands. A
nonempty dynamic set can be classified as throwing before resolving its names.
Class-ready edges and unit-deferred edges have separate owners: an unrelated
class event never polls the unit-deferred queue. Unit completion resolves the
recorded specifications and consumes those edges once. Unresolved final facts
are invariant errors. Implicit destructor sets traverse only recorded base
and non-reference member edges with an explicit visited worklist, retaining
finite unions rather than treating every potentially throwing destructor as
unrestricted. Handler matching preserves reference restrictions, public unique
base conversions, pointer qualification, void pointers and nullptr.

An implicit virtual destructor records class-level inherited identity and
nontriviality without eagerly allocating an unused callable identity. Completed
nonthrowing and deletedness checks retain the C++ diagnostic owner/location.
The later vtable/lifecycle group must publish demanded implicit callable/slot
facts and select virtual deallocation functions before emission.

The two ownership/scheduling regressions verify original syntax counts,
shared override identities, pure-count transitions, no unused layout/body or
implicit callable demand, and a pending noexcept edge untouched by an unrelated
class completion. New maps have private typed APIs and flat owned storage;
query scratch dies with its query, and the completion queues die with the
analyzer. No optimizer, register allocator or native code owner changed; all
existing per-function lowering/backend lifetimes remain intact. No dependency,
unsafe code, environment/process read, fixture recognition or textual phase
transport was introduced.
