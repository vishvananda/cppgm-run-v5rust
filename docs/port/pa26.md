## Completed behavior group: host objects without landing pads

- Default/explicit `.o` source compilation now uses host objects. `.obj` and
  direct source-link mode retain course objects. A typed `ObjectModel` travels
  through the definition sink and selected function; no environment read was
  introduced under `dev/src/`.
- Every retained host function gets a plain FDE, including functions through
  which a host exception merely passes. A frameless jump thunk/TLS wrapper
  uses the CIE's entry rules. No function body is retained for table writing.
- Each branch-relaxation pass records actual push, frame establishment,
  callee-save and leave/ret offsets. Only the final pass is consumed. CFI uses
  the frozen DWARF register mapping and offset units; it is not inferred from
  a fixed prologue or reparsed machine text.
- An object-owned flat CFI pool and range spans outlive each function's MIR.
  Pruning determines which spans are placed; FDEs follow held-definition
  release order, like text and symbols. The deferred-unwind continuation below
  corrects checkpoint 1's physical-order walk.
  `.eh_frame` follows globals/startup. Section symbols and PC32 unwind
  relocations follow ordinary symbol/relocation construction in oracle order.
- Undefined host imports use STT_NOTYPE. The nine reserved builtin object
  spellings map to host names through interned `NameId` identities, preserving
  shared aliases with ordinary foreign declarations. An undefined function or
  data address's RIP-relative LEA becomes the exact GOT load/REX_GOTPCRELX
  reference, using final typed symbol placement facts. General imported data
  memory operands remain an explicit status-86 boundary.
- Readonly globals containing typed address items use shared or per-COMDAT
  `.data.rel.ro`, with the frozen alignment, group and relocation order. This
  includes emitted class type information; fundamental exception RTTI remains
  imported.
- O0 host narrow integer parameters are extended on entry only when the frozen
  observation rules require it. Per-function origin masks propagate through
  typed aliases and bitwise results to a finite monotone fixed point. Compares,
  stores, call arguments, arithmetic, small masks and truncations retain their
  width-safe distinctions. Boolean normalization uses `and i64, 1`. Course
  entry behavior is unchanged.

The frontend still parses once and supplies recorded types, runtime roles,
publication order and initializer items. Selection consumes those typed facts;
CFI consumes encoder facts. After each append, MIR/selection owners die and
LowIR bodies are released by the existing definition stream. Final object
placement uses only native ranges, compact IDs, CFI spans and LowIR symbol/
global metadata. There is no owning syntax/semantic edge in the backend.
