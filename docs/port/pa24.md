## Completed behavior group and architecture review

The backend consumes one validated typed LowIR `Program`, without textual phase
transport. Names, symbols, signatures, slots and temporaries retain compact IDs.
One selected function owns ABI placements, aliases, slot facts, MIR and assembler
labels; that transient state is released before selecting the next function.
The image retains only emitted bytes, definitions, typed fixups and interned
scalar constants. Constant keys use fixed 16-byte storage, not per-key vectors.

Supported O0 single-block bodies include const/copy alias chains, unused/dead
locals, provably promoted store/load locals, void and scalar constant returns,
full i128 split-word returns, scalar incoming GPR returns, symbol-address returns
and traps. Floating scratch requirements account for unused floating parameters
and dead floating inputs, matching the C++ selector. Incoming ABI rows preserve
whole-object fallback when one register class is exhausted. Immediate bits are
retained independently of their signed low-word assembly encoding: split i128
words use the frozen zero-extended `make_imm` view. Debug filenames preserve raw
bytes and the C++ string's first-NUL boundary.

Standalone executable output includes actual function bytes, constant pools,
all globals in definition order, readonly globals in the same data section,
RIP-relative and absolute data fixups, EH BSS and dispatcher, process startup,
optional init/fini, declared builtins, atexit pages and TLS wrappers. The writer
preserves headers, segment offsets/addresses, function alignment, trailing-zero
elision and BSS placement. MIR and encoding consume the same selected facts.
Unsupported operations continue to return status **86**; that is never counted
as a valid oracle rejection. No new optimization or allocator policy is added.

Target arithmetic is distinct from host storage arithmetic: raw global spans
wrap u64, ABI stack positions wrap u32 then retain signed i32 displacements,
and object alignment follows the frozen 32-bit shift. Safe virtual-span and
unused-argument probes exercise these boundaries without allocating giant
objects. Checked conversions, reservations and slice ends protect actual host
buffers. `alignment-probe.cpp` in the evidence directory includes the read-only
frozen header to confirm its host shift behavior for align logs 0–47; it is an
external test helper, never compiler implementation or fallback.

No dependency, unsafe/FFI implementation, compiler subprocess, fixture lookup,
environment read in `dev/src/`, broad lint suppression or generated source was
added. Two narrow argument-count expectations describe independent x86/ELF
fields. Platform executable permissions enter through typed driver options.
The existing optimizer is unchanged. Source files have cohesive owned roles,
rather than mechanical fragments, and remain subject to the companion audit.
