## Typed data flow and architecture review

Syntax is parsed once. Sparse facts keyed by the original ExprId retain a
canonical queried TypeId and dynamic flag, or selected identity-operator marker.
Parentheses share the original fact; lowering resolves the original binary
syntax before consuming its identity marker. Normalization reuses the owning
scalar conversion algorithm, including recursively cv-unqualified array elements.
No names or rendered types serve as semantic keys.

Operand analysis temporarily collects typed function/local/this/variable/error,
query and constructor uses, then replays them in order only for a polymorphic
glvalue. Enclosing unevaluated contexts collect the replay in turn. Failed
analysis restores the saved context and truncates uses. The new rollback unit
test verifies restoration and unchanged syntax expression count. The original
noexcept trait rule remains separate from lowering's dynamic operand scans.

Canonical RTTI dependencies are memoized once by TypeId. Function-owned
TypeInformation storage demands enter the existing unit-tail scheduler. Thus a
pointer query before a later class definition receives the final layout, while
a pointer-only incomplete class-template specialization stays uninstantiated.
Class layouts and unrelated member bodies retain their existing separate demand
boundaries. Repeated requests deduplicate by function owner and queried type;
type dependency layouts are processed once at that boundary. No whole-program
poll, speculative specialization completion or lowering-time semantic query is
introduced.

Constant addresses carry TypeInformation(TypeId), distinct from variables or
strings. Publication retains this identity until data lowering selects its ABI
symbol. Program-owned RTTI objects memoize canonical type identity, use typed
runtime-kind and ABI-target enums, and reuse class RTTI emission. Deferred class
RTTI declarations merge with ordinary referenced declarations by SymbolId
creation order; definitions and runtime vtable declarations publish at their
original encounter points. A descriptor naming a base can define that base's
information even after an earlier use left a declaration pending.

Dynamic queries read the evaluated object's primary vptr and the -8-byte type
information slot. Only an original builtin unary dereference tests for null.
The failure retains the frozen raw no-return call and zero/fallback return,
including object-return slot placement. Query instructions, temporary cleanup
state and backend lifetimes remain per function. Static discarded queries emit
no RTTI just because their syntax was seen.

Independent audit should trace the unevaluated/evaluated lambda capture pair,

query before a later base-bearing definition, constexpr aggregate RTTI storage,
an external-key class pointer mixed with ordinary global references, and a
